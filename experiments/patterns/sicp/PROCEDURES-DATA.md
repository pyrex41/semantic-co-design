## Read the operation counts

The checker compares independent answers and reports work on its fixtures. In the interval fixture, 49 operand pairs take 196 endpoint products by direct enumeration and 86 with the staged formulas. The GCD fixture compares 2,794 Euclidean remainders with 964 residual remainders. The painter fixture evaluates 54 endpoint maps through the nested frames and 30 after affine composition. A Huffman decoder still executes one table transition per input bit. A hash set lookup can still make equality checks internally.

For the generated recurrence step, powers, derivative and polynomial product, the checker also verifies that no bytecode loop scans the static descriptions. The counts concern work at the call boundary and omit the one-time setup cost. Fixed exponents and polynomial supports generate straight-line code whose size grows with the arithmetic schedule. Fold and painter compilation recurse through their fixed input structures. The painter fixture uses exact coordinates so it can compare rearranged affine arithmetic exactly. Floating-point coordinates can introduce different rounding under composition.
